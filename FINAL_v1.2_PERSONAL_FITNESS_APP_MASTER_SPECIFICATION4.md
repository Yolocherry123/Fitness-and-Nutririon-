# 4. BODYWEIGHT GAIN SYSTEM

## Daily weigh-in
When practical:
- weigh in after waking,
- after using the bathroom,
- before eating/drinking,
- under similar conditions.

The app should prioritize the 7-day average rather than reacting strongly to one day's scale change.

## Review logic
Do not change calories based on only a few days.

After sufficient consistent data:
- If average bodyweight is not increasing adequately for multiple weeks and adherence is reasonably good, add approximately 100–150 kcal/day.
- If weight is increasing excessively fast for multiple weeks, reduce approximately 100–150 kcal/day.
- If progress is appropriate, make no change.

The app must explain WHY any adjustment is recommended.

Example:
"Your recent average bodyweight has not increased sufficiently despite consistent nutrition completion, so the app recommends adding approximately 100–150 kcal/day."

Never recommend a calorie adjustment when there is insufficient reliable data.

# 21. SAFETY / PAIN RULE

Normal training sensations may include:
- muscular effort,
- fatigue,
- ordinary delayed soreness.

Warning signs include:
- sharp pain,
- worsening pain during movement,
- concerning joint pain,
- symptoms that make safe movement difficult.

The app should instruct the user to stop the problematic exercise rather than blindly pushing through pain.

# 23. IMPROVEMENT LAYER — DAILY PRIORITY SYSTEM

When the day is busy, the app should prioritize actions in this order:

## Tier 1 — Highest priority
- Eat the main meals available.
- Complete the planned workout or recovery action when appropriate.
- Get adequate protein from the day's available foods.
- Maintain the overall calorie-surplus strategy.
- Sleep and recover.

## Tier 2 — Helpful
- Anabolic bowl
- Scheduled chicken/kebab addition
- Creatine consistency
- Bodyweight logging

## Tier 3 — Optional optimization
- Whey
- nuts
- chia
- flax
- sprouts
- ghee
- extra calorie tools

This prevents the user from believing that skipping an optional item means the whole day failed.

# 24. APPETITE / LOW-APPETITE MODE

If appetite is temporarily poor, do not immediately force huge meals.

The app should offer easier nutrition options:
- prepared milk from milk powder
- banana
- peanut butter
- smaller portions distributed across the day
- whey when useful
- curd/yogurt when tolerated
- other practical calorie-dense foods already available

Use food additions strategically rather than automatically increasing fiber.

---

# 25. PROTEIN GAP LOGIC

The app should estimate a daily protein gap when meal protein has been logged with reasonable confidence.

Priority order for closing a gap:
1. Use protein already available in the next normal meal.
2. Use scheduled chicken/kebab when applicable.
3. Use convenient foods such as eggs, curd, milk, paneer, etc. when available.
4. Use whey when convenience is the main advantage.

Do not automatically prescribe whey merely because the user trained.

---

# 26. CALORIE GAP LOGIC

If the user appears short of the planned calorie intake, the app should suggest ONE practical addition first.

Suggested order:
- extra banana
- peanut butter
- milk / milk-powder drink
- PB sandwich
- extra oats
- nuts
- small amount of ghee with food

Do not stack every calorie tool unless the user deliberately chooses to.

---

# 27. FOOD SAFETY & STORAGE RULES

The app should distinguish between:
- dry foods,
- refrigerated prepared foods,
- freshly cooked foods.

For milk-based bowls or other perishable prepared foods:
- use a clean airtight container,
- refrigerate promptly,
- avoid leaving them at room temperature for the entire day.

The app should not provide false universal storage times when temperature and preparation conditions are unknown.

---

# 28. CHICKEN LOGGING CLARITY

Chicken entries must distinguish:
- raw weight,
- cooked edible meat,
- bone-in serving.

Bone-in weight is not equivalent to edible meat weight.

For nutrition tracking, the app should allow the user to choose the measurement type instead of silently assuming all chicken quantities represent the same amount of edible protein.

# 30. WEEKLY REVIEW GUARDRAILS

This is better than automatically increasing calories when the plan was simply not followed.
