Saturday is a quality-focused calisthenics and skill day.

It should improve:
- movement quality,
- pulling strength,
- pressing strength,
- core control,
- skill progression.

It should NOT become an uncontrolled high-fatigue workout that damages recovery for Monday.

# 8. PROGRESSION SYSTEM

## Double progression

For an exercise with a rep range:

Example:
3 × 8–12

Progression:
1. Start with a manageable load/variation.
2. Improve repetitions while maintaining form and target RIR.
3. When the top of the rep range is achieved appropriately across the planned work sets, increase difficulty.
4. Restart nearer the lower end of the range.
5. Build up again.

The app should track:
- load
- reps
- RIR
- completion quality

---

# 9. IMPORTANT WEIGHT-INCREMENT RULE

Do not increase weight after every individual set.

Track performance across the workout session and across sessions.

Example:
Exercise:
3 × 8–12

Session:
10, 10, 9

Next time:
Attempt to improve performance while maintaining form.

Only increase load when the progression criteria are met.

The app should recommend an increase only when appropriate, not after one unusually good set.

---

# 10. CALISTHENICS PROGRESSION

Progression can occur through:
- more reps,
- better range of motion,
- cleaner technique,
- more difficult variation,
- additional external weight when appropriate.

Do not increase difficulty if technique deteriorates substantially.

---

# 11. RIR SYSTEM

RIR = Reps In Reserve.

Examples:
- RIR 2: approximately two good reps could still have been performed.
- RIR 1: approximately one good rep remains.
- RIR 0: technical failure / no further good rep expected.

The plan generally uses:
- RIR 1–2 for many working sets,
- controlled training rather than constant failure.

The app should allow actual RIR to be logged.

---

# 12. REST PERIODS

Default practical ranges:

Heavy compound movements:
- approximately 2–3 minutes

Moderate compound/accessory movements:
- approximately 1.5–2 minutes

Smaller isolation movements:
- approximately 1–2 minutes

The app should allow customization rather than treating timers as absolute.

---

# 13. WARM-UP RULE

Before working sets:
- perform general movement preparation,
- use lighter ramp-up sets when appropriate,
- do not count ordinary warm-up sets as primary working sets.

The app should support separate warm-up and working-set logging.

---

# 14. MISSED WORKOUT LOGIC

Preferred system:
Do not treat a missed weekday as permanent failure.

However, recovery matters.

App behavior:
1. Mark workout as missed.
2. Offer:
   - reschedule when recovery allows,
   - skip and continue the plan,
   - manually choose next session.
3. Do not automatically stack multiple hard workouts into one day.

The app should show the current training sequence and avoid creating unsafe catch-up behavior.

---

# 15. FATIGUE / DELOAD LOGIC

Potential signs requiring review:
- persistent unusual fatigue,
- declining performance across multiple sessions,
- poor recovery,
- persistent soreness,
- reduced motivation combined with poor performance.

Possible action:
- reduce training stress temporarily,
- use a lighter week,
- maintain technique and movement quality.

Do not trigger a deload based on one bad workout alone.

---

# 16. PAIN RULE

Stop and reassess an exercise if there is:
- sharp pain,
- worsening pain,
- concerning joint pain.

Do not simply instruct the user to push through.

The app should offer:
- stop exercise,
- substitute movement,
- record issue,
- seek appropriate professional advice when necessary.

Quality form + consistent training + gradual progression

is more important than increasing weight as quickly as possible.

# 19. SATURDAY SKILL PROGRESSION RULE

Saturday skills should not all be trained maximally in one session.

The app should allow the user to choose:
- Primary skill
- Secondary skill
- Optional skill

Example:
Primary: Handstand progression
Secondary: L-sit progression
Optional: Muscle-up preparation

Keep the session focused and avoid excessive fatigue before technical skill practice.

---

# 20. SESSION QUALITY CHECK

After each workout, optionally record:

- Too easy
- Appropriate
- Hard but manageable
- Excessive fatigue

This should influence review discussions but should not automatically change the program after one session.

---

# 21. EXERCISE SUBSTITUTION RULE

If equipment is unavailable, substitutions should preserve the movement pattern where practical.

Examples:
- vertical pull → another vertical pull variation
- horizontal row → another horizontal row variation
- squat pattern → another squat pattern
- hip hinge → another hip-hinge pattern
- horizontal push → another horizontal push variation

The app should retain the original exercise history while recording the substitute separately.

---

# 22. PROGRAM REVIEW TRIGGERS

Prompt a training review when:
- performance has plateaued for a sustained period,
- bodyweight has changed substantially,
- equipment changes,
- recovery becomes consistently poor,
- the user reaches a major bodyweight milestone.

Do not change the program merely because of one bad workout.
